# glowing-waffle

A simple HTML5 vertical scrolling shooter game built with Node.js and Phaser 3.

## Description

This is a classic vertical scrolling shooter game template. Control a spaceship, shoot enemies, and try to get the highest score!

## Features

- Player ship with smooth movement controls
- Shooting mechanics
- Enemy spawning system
- Scrolling starfield background
- Collision detection
- Score tracking
- Game over and restart functionality

## Installation

```bash
npm install
```

## Running the Game

```bash
npm start
```

Then open your browser and navigate to `http://localhost:3000`

## Controls

- **Arrow Keys** or **WASD** - Move the ship
- **Space** - Shoot
- **R** - Restart game (after game over)

## Technology Stack

- Node.js
- Express (web server)
- Phaser 3 (game framework)
